# Nuvero AI: Instagram Carousel Studio & Rendering Engine

Production-ready Instagram Carousel rendering studio and 2x Retina PNG export suite for **[Nuvero AI](https://nuvero.space)**.

---

## 🎨 Visual Identity & Brand System

Built in strict compliance with the **Nuvero Master Brand Guide (v4.0)**:
* **Nuvero Tan (`#FDF0D5`):** Warm dominant canvas with technical micro-grid.
* **Nuvero Blue (`#003049`):** Primary structural ink for typography and borders.
* **Nuvero Red (`#C1121F`):** High-impact focal highlight for key numbers and tags.
* **Nuvero Dark Red (`#780000`):** Shadow depth and secondary accents.
* **Typography:** Inter + Space Grotesk + IBM Plex Mono.
* **Zero Em Dashes:** Strict compliance across all copy, diagrams, and captions.

## 📱 Features

1. **4 Complete Carousel Case Studies:**
   - **Post 01: Voice Agent Concierge (Southwest Gases)**
   - **Post 02: Multilingual WhatsApp Copilot (GoHappy Club)**
   - **Post 03: Autonomous Campaign Engine (Marketrz Agency)**
   - **Post 04: Single-Window Quoting Platform (Adfactors PR)**
2. **Aspect Ratio Switching:** 4:5 Portrait (`1080 × 1350 px`) and 1:1 Square (`1080 × 1080 px`).
3. **High-Res Export Engine:** Crisp 2x Retina PNG single-slide and batch-download exports.
4. **Copywriting Assistant:** 1-click Instagram caption copier with zero em dashes.
